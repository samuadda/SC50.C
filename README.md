## 🛠️ How to Compile & Run

To compile any file, you can use `gcc`:

```bash
gcc filename.c -o program
./program
```

Or, if you’re using the CS50 environment / make:
```bash
make program_name
./program_name
```
Make sure you have a C compiler installed (e.g. gcc or clang).
